# Uber Ride Analysis Using MySQL

## Project Overview

This project analyzes Uber ride booking data using MySQL to understand booking performance, revenue trends, ride cancellations, popular locations, and customer experience.

The objective is to use SQL to explore ride data and identify business insights that can support operational improvements and better decision-making.

## Business Objectives

* Analyze completed, cancelled, and incomplete bookings.
* Compare booking volumes across vehicle types.
* Identify monthly and hourly booking trends.
* Evaluate revenue and average booking value by vehicle type.
* Investigate customer and driver cancellation patterns.
* Identify popular pickup locations, drop locations, and routes.
* Analyze cancellation rates by vehicle type and pickup location.
* Compare customer ratings and average VTAT and CTAT across vehicle types.

## Tools and Technologies

* MySQL
* SQL
* MySQL Workbench

## SQL Concepts Used

* SELECT and WHERE
* GROUP BY and ORDER BY
* Aggregate functions: COUNT(), SUM(), AVG()
* Date and time functions: MONTH(), HOUR(), STR_TO_DATE()
* HAVING clause
* ROUND() and LIMIT
* Conditional aggregation
* Percentage calculations

## Analysis Areas

### 1. Ride Booking Performance

Analyzes booking status, booking volume by vehicle type, monthly trends, and peak booking hours.

### 2. Revenue Analysis

Compares total and average booking values across vehicle types.

### 3. Cancellation Analysis

Examines customer and driver cancellations, cancellation reasons, and cancellation rates across vehicle types.

### 4. Location and Route Analysis

Identifies popular pickup and drop locations, frequently used completed routes, and pickup locations with high cancellation rates.

### 5. Customer Experience

Evaluates average VTAT, CTAT, and customer ratings by vehicle type.

## Business Value

The analysis can help identify peak booking periods, understand cancellation patterns, evaluate vehicle-type performance, and highlight opportunities to improve ride availability and customer experience.

## Key Learning Outcomes

* Writing SQL queries to answer business questions.
* Analyzing booking and revenue metrics.
* Working with date and time functions.
* Investigating cancellations and location-based patterns.
* Translating analytical questions into SQL queries.
